## Proposed Phase 1 — Baseline security hardening (detailed)

**Precondition:** Phase 0 inventory done (we need current SSH config, users, IP
setup, pending updates). Steps below may be adjusted after discovery.

**Lockout safety net for the whole phase:** physical console access (keyboard +
monitor) to the NAS must be available, and the OMV web UI stays reachable on
HTTP until HTTPS is verified. SSH changes are made with an existing session kept
open and a *second* session used for testing.

**Objective:** reduce the attack surface and establish trustworthy administration
before any data is stored. No disk, share, or data changes in this phase.
